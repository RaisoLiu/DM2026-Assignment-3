# DM2026 Assignment 3: Human Activity Recognition

This repository contains a reproducible pipeline for the DM2026 Assignment 3
Kaggle competition. The task is to predict one activity label for each
5-minute accelerometer window.

## Data Download and Layout

Download the Kaggle files and place them under `data/raw/`:

```bash
kaggle competitions download -c nycu-data-mining-assignment-3 -p data/raw --force
unzip -q -o data/raw/nycu-data-mining-assignment-3.zip -d data/raw
```

The archive contains `train/train/User_*` and `test/test/User_*`; move the
`User_*` directories one level up so the final layout is:

```text
data/raw/
  train/
    User_xxx/
      *.csv
  test/
    User_xxx/
      *.csv
  sample_submission.csv
```

The loader also accepts `labels.csv`, `train_label.csv`, or a `Label`/`label`
column inside each training CSV. Each per-window CSV should contain `file_id`,
`index`, `mean_x`, `mean_y`, `mean_z`, `std_x`, `std_y`, and `std_z`.

Kaggle invite link from the assignment PDF:
`https://www.kaggle.com/t/7177902eb8b34b25a75e932d4e235b32`

## Run a Smoke Check

This validates imports and CLI wiring without needing the Kaggle data.

```bash
python scripts/run_experiment.py --help
python scripts/make_submission.py --help
python scripts/make_boosting_submission.py --help
```

## Selected Reproduction Commands

```bash
python scripts/run_experiment.py \
  --data-dir data/raw \
  --output-dir artifacts/hgb_fast_5fold \
  --feature-cache-dir artifacts/features \
  --n-splits 5 \
  --seed 2026 \
  --fast \
  --models hist_gradient_boosting

python scripts/make_boosting_submission.py \
  --results-csv artifacts/model_search_position_proba/results_position.csv \
  --model lgbm_leaves63 \
  --context position \
  --output submissions/submission_lgbm_leaves63_calibrated.csv \
  --seed 2026
```

`run_experiment.py` writes grouped-CV metrics, class calibration weights,
dataset summaries, selected features, and report-ready tables for the HGB
baseline and ablations. `make_boosting_submission.py` trains the selected
LightGBM model on all available labeled windows and writes a Kaggle-compatible
`Id,Label` CSV aligned to `sample_submission.csv`.

The current selected public Kaggle score is `0.8106`, generated by
`lgbm_leaves63` with position context features and seed `2026`.

## Ablations

Feature-family ablations for the HGB baseline can be reproduced with:

```bash
python scripts/run_experiment.py \
  --data-dir data/raw \
  --output-dir artifacts/hgb_fast_5fold_ablation \
  --feature-cache-dir artifacts/features \
  --n-splits 5 \
  --seed 2026 \
  --fast \
  --models hist_gradient_boosting \
  --run-feature-ablations \
  --ablation-model hist_gradient_boosting
```
